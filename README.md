# netpractice - 42 | [FRENCH VERSION] *english below*

## 📚 Description

`netpractice` est un projet de l'école 42 conçu pour apprendre les bases des **réseaux informatiques**.
Le but est de résoudre une série d'exercices en configurant correctement des réseaux IPv4 : adresses IP, masques de sous-réseau, passerelles et routage.

Chaque niveau présente une topologie réseau différente où il faut identifier et corriger les erreurs de configuration afin de rétablir la communication entre les machines.

---

## 📦 Objectifs

* Comprendre le fonctionnement des adresses IPv4
* Maîtriser les masques de sous-réseau et le subnetting
* Configurer les passerelles (gateways) et le routage
* Analyser et corriger des erreurs de configuration réseau
* Développer les bases nécessaires à l'administration réseau

---

## 🧠 Concepts abordés

* Adresses IPv4
* Masques de sous-réseau
* Sous-réseaux (Subnetting)
* Passerelles (Gateways)
* Routage
* Communication entre hôtes

---

## 🚀 Validation

Le projet se réalise directement dans l'interface **NetPractice** de 42.

Chaque niveau doit être entièrement configuré avant de pouvoir passer au suivant.

# netpractice - 42 | [ENGLISH VERSION]

## 📚 Description

`netpractice` is a project from the 42 curriculum designed to teach the fundamentals of **computer networking**.
The objective is to solve a series of exercises by correctly configuring IPv4 networks, including IP addresses, subnet masks, gateways, and routing.

Each level presents a different network topology in which configuration errors must be identified and fixed to restore communication between hosts.

---

## 📦 Objectives

* Understand how IPv4 addressing works
* Master subnet masks and subnetting
* Configure gateways and routing
* Analyze and fix network configuration errors
* Build a solid foundation in computer networking

---

## 🧠 Concepts Covered

* IPv4 addressing
* Subnet masks
* Subnetting
* Gateways
* Routing
* Host-to-host communication

---

## 🚀 Validation

The project is completed directly through the **NetPractice** interface provided by 42.

Each level must be fully configured before progressing to the next one.
